## 💡 特性

- **原汁原味** — 熟悉的 macOS 启动台交互，图标排列、搜索、翻页全部保留
- **Liquid Glass** — 顶部导航采用毛玻璃折射效果，通透灵动
- **思考牛彩蛋** — 右下角思考牛，hover 触发挠头帧动画
- **响应式适配** — 桌面端 / 移动端均有优化体验
- **已适配 macOS 27** — 最新系统兼容
